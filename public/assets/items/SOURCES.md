# Item artwork

Source: https://wosgift.com/zh-cn/items/

Original item images downloaded for local reference display. Game artwork belongs to its respective rights holders. Names and categories are retained as source metadata; game rules, prices and descriptions are not imported.

Per-image source URL, local path, dimensions and SHA-256 are recorded in src/data/item-art.json.

Current scope (2026-10-25): 47 images required by the model and recorded expert pack rewards. Unused source artwork is outside the application assets, in reference-archive/item-art-2026-10-25.

Additional icon: https://wos-helper.com/guide-troop-calc.php ; original asset: https://wos-helper.com/assets/img/icon_speedupGeneral.a614ca7e.webp
General speedup arrows have no duration lettering; used as the one-hour speedup representative. Legendary gear uses the legendary gear choice chest icon at the maintainer request.

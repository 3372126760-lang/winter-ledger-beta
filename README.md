## 数据口径

价格和升级消耗来自冬日工具箱在2026-10-24的公开数据快照，仍标为待复核，不代表游戏官方确认。

原资料“火晶三前”按用户定义归为火晶前；“一阶段”须按每种礼包分别判断，未自动归入火晶前。T11对应原战争学院进度。早期数据是具体渠道折算，并非完整统一估值。未提供价格保留未知，不按零元处理，不自动跨阶段推断。

资料读取范围包含C盘参考资料，但项目代码和输出只在本F盘项目中维护。当前应用运行时不读取C盘资料。

## 个人校对记录

在“礼包资料”中选择一个分段，填写适用进度、奖励规则和确认依据后保存。适用进度可以多选；只修订奖励规则时，不勾选进度以沿用原始标注。每条校对只作用于该分段，不会把所有“一阶段”一起归类。

记录存放在浏览器备份的 `offerReviews` 字段中，不修改 `src/data/offers.json`。旧版备份缺少该字段时自动迁移为空记录。恢复原始资料只移除个人校对，不修改原始快照、价格设定、库存或礼包草稿。

校对依据包含原始礼包名称、备注、分段顺序、档位和原始材料数量。更新资料后出现变化时，旧校对保留但不生效，需重新核对并保存；仅内部单位映射说明变化不会触发失效。来源已无对应记录时，同样保留校对依据供查看和清理。

个人校对不会自动生成基准单价，也不代表资料已获游戏官方确认。

## 名称与宝箱期望（v0.6）

按 WosGift 道具名称统一16个已明确身份的名称，旧名称保存于 aliases，原有道具ID、库存和礼包草稿保持兼容。原始礼包的名称、数量及校对依据不改写。笼统的宠物箱子、英雄装备自选箱、英雄组件自选箱及N-1代组件箱仍需确认具体身份，不强行匹配。专家好感度等计量项保留为模型指标，不伪装成网站某件道具。

`src/data/catalog.json` 内 valuation 为维护者统一管理的估值规则。固定宝箱把所有奖励相加，随机宝箱按概率加权，并使用对应进度的基础道具单价及priceScale换算。基础道具调价后，依赖它的箱子自动重算；原prices里的箱子数值仅为旧资料归档，不回退使用。缺少任一非零期望材料价格时，箱子保持缺价；不把缺项视为零元。价格表展开“查看期望计算”可查看奖励、概率、期望数量、价值和来源。

已接入领主装备材料宝箱、领主装备材料随机宝箱、领主宝石材料随机宝箱和火晶宝箱的期望计算。英雄装备幸运宝箱保持原参考价，反推传说英雄装备单价。宠物突破材料自选箱和英雄战歌自选箱记录可选奖励，未指定选择时不计算随机平均或全部相加。原“宠物箱子”的具体身份未知，旧价暂不参与估值。

英雄装备幸运宝箱采用网站基础概率：稀有89%、史诗10%、传说1%。维护者指定稀有装备=0.6个强化经验零件、史诗装备=1.5个零件，并叠加最多100箱出传说装备规则。模型按出传说后重置计数、第100箱替代普通奖励处理。平均周期为 sum((1-p)^k,k=0..99)，长期传说比例为该周期倒数；其他奖励按剩余比例保持89:10。这是长期每箱平均价值，不是当前保底计数下单次或有限批次的预测，不保证任意100箱收益恰好等于100倍参考价。

七代火十：平均周期63.3967658727箱，传说长期比例约1.57736753%；幸运宝箱固定0.833元，反推传说英雄装备33.1942317549元；领主装备材料宝箱0.735元，领主装备材料随机宝箱0.9485325元，领主宝石材料随机宝箱0.965625元，火晶宝箱4.3735808元。以上基础单价仍待复核，不等于可按此价格购买。


2026-10-25维护者纠正：装备幸运宝箱不重新定价，固定使用原资料中的分进度参考价。将100箱保底纳入分布，蓝装与紫装分别折算0.6、1.5个强化经验零件，由（箱价－蓝紫装备期望价值）／传说装备期望数量反推橙装。传说装备prices中的旧数值仅归档；缺少箱价或零件价时不自动回退旧橙装价。若已知奖励价值超过箱价，标记依据冲突并停止反推。
